Hotel Management System Guide

System User Manual

Use this guide to understand each module and the main workflow for managing hotel operations.

Quick Workflow
  1. Configure hotel settings, room types, meals, and services.
  2. Create rooms and keep room statuses updated.
  3. Register customers and create bookings.
  4. Check in guests when they arrive.
  5. Place guest food and drink orders when requested.
  6. Generate bills, record payments, and check out guests.
  7. Review reports and manage users, roles, and permissions.
Helpful Notes
Required permissions Some modules are only visible when your role has access.
Active hotel Use the hotel switcher in the sidebar to work with a specific hotel.
Data accuracy Keep bookings, room status, and payments updated for accurate reports.
